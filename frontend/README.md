# CyberGuard frontend

Next.js (App Router), React 19, TypeScript, Tailwind CSS v4, SWR, Recharts.

1. `npm install`
2. Copy `.env.example` to `.env.local`. `BACKEND_URL` is where Spring Boot runs; `/api/*` is proxied there.
3. `npm run dev` opens http://localhost:3000

Scripts: `dev`, `build`, `start`, `lint`, `typecheck`, `test:e2e` (Playwright).
